**PocketStudio DSP** is a professional, mobile-first multi-track audio editor built entirely with web technologies. It features a high-performance audio engine based on the Web Audio API, real-time DSP effects, and tensor-field visualization aesthetics.

## 🚀 Features

### Core Audio Engine
- **Multi-Track Mixing**: unlimited tracks with individual volume, pan, mute, solo, and arming.
- **Non-Destructive Editing**: Move, split, copy, paste, and delete clips non-destructively.
- **Real-Time DSP**: Low-latency effects processing chain per track.
- **Offline Bouncing**: High-speed rendering of the final mix to MP4/WAV.
- **Input Monitoring**: Real-time microphone input visualization and processing.

### DSP Rack & Effects
- **Dynamics**: Look-ahead Compressor, Noise Gate / Expander.
- **EQ**: 3-Band Parametric EQ + High Pass Filter + Presence (Air).
- **Modulation**: 4-Stage Phaser, Stereo Chorus, Flanger.
- **Color**: Tube Saturation, Bitcrusher, Cabinet Simulator.
- **Spatial**: Algorithmic Reverb, Stereo Delay.
- **Master Bus**: Multiband compression, Limiter, and Stereo Widening.

### Visualization
- **Tensor Field Waveforms**: Dynamic waveform rendering using canvas gradients.
- **Candlestick Mode**: Financial-style audio analysis (High/Low energy vs Peak/RMS).
- **Real-Time Metering**: Smooth RMS metering and spectral analysis.
- **Interference Background**: Generative background visuals reacting to user input.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Audio**: Native Web Audio API (AudioWorklet ready structure)
- **State**: React Hooks + Refs for high-frequency audio loops
- **Storage**: IndexedDB for large audio blob persistence

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/pocketstudio-dsp.git
   cd pocketstudio-dsp
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm start
   # or
   yarn start
   ```

## 🎮 Controls

- **Space**: Play / Pause
- **S**: Split clip at playhead
- **Delete / Backspace**: Delete selected clip
- **Ctrl/Cmd + C**: Copy selected clip
- **Ctrl/Cmd + V**: Paste clip at playhead
- **Double Click Fader/Knob**: Reset to default value

## 📱 Mobile Support

The UI is designed with a "Mobile-First" approach, featuring:
- Large touch targets (48px+).
- Pinch-to-zoom on the timeline.
- Collapsible channel strips.
- Touch-friendly knob and slider interactions.
